# BullRider

BullRider 是一个面向 **A 股新手**的开源**量化信号与风险管理工具**：行情、策略信号、历史回测、模拟盘、实盘记录、AI 教练一体，采用"一切皆插件"的架构，陪零基础用户走完"看懂市场 → 验证策略 → 管理风险"的完整路径。关键决策和下单仍由用户确认。

> **免责声明**：本项目仅供学习与研究，不构成任何投资建议。股市有风险，入市需谨慎。

## 功能特性

- **行情与信号**：沪深 A 股 + 场内 ETF 实时行情，双数据源（东财主源 + 腾讯备源）自动切换与熔断；六种策略信号——均线金叉、RSI、MACD、唐奇安突破、布林带，以及按近 60 天回测收益动态定权的**策略赛马**
- **历史回测**：任一标的 × 任一策略的账目级回测（佣金/印花税/T+1），信号在下一交易日开盘成交，对比买入持有基准
- **选股推荐**：漏斗式扫描沪深主板（快照粗筛 → 策略赛马精算）+ 主流场内 ETF 白名单，产出按买方权重排序的 BUY 名单
- **信号质量追踪**：给策略每次喊买记账，等卖出信号（或超时）按收盘价验收，用大样本胜率/盈亏比回答"这策略到底准不准"
- **模拟盘**：虚拟资金全流程演练，下单自动过风控（单股仓位/总仓位/止损）
- **实盘记录**：手工同步真实券商成交，移动加权计算真实持仓，并按现价、成本、ATR 和赛马趋势给出风控止损、技术保护与两档分批止盈参考
- **AI 教练**：接入任意 OpenAI 兼容端点（API Key 由服务端 AES-256-GCM 加密存储，界面只显示掩码，已保存 Key 固定绑定保存时的端点），用通俗中文解读行情与操作

## 快速开始

环境要求：[Node.js](https://nodejs.org) `^22.19 || >=24`、[pnpm](https://pnpm.io) `11.7.0`。

```sh
pnpm install
pnpm web
```

打开 `http://127.0.0.1:3080` 即可使用。

命令行方式（可选）：

```sh
pnpm fetch 600519                  # 拉取日K + 基础分析
pnpm signal 600519                 # 计算买卖信号
pnpm backtest 600519               # 历史回测
pnpm paper buy 600519 --amount 20000  # 模拟盘买入 2 万元
```

## 页面一览

| 页面 | 用途 |
| --- | --- |
| 行情 | 实时行情、K线、六策略信号 |
| 选股推荐 | 全市场漏斗扫描 + ETF 白名单、信号质量统计 |
| 回测 | 历史回测与策略对比 |
| 模拟盘 | 虚拟资金演练，下单自动过风控 |
| 实盘记录 | 手工同步真实成交、持仓赛马建议 |
| AI 教练 | 问答式股票入门与行情解读 |

## 架构

TypeScript + pnpm，**一切皆插件**——基于 [Cordis](https://github.com/cordiverse/cordis) 插件内核，架构参考 [deepseek-harness](https://github.com/deepseek-ai/deepseek-harness)：

| 模块 | 职责 |
| --- | --- |
| `market-data` | 行情数据源缝：Provider 可插拔，双源故障转移 + 熔断，本地缓存 |
| `signal` | 策略信号缝：六种策略 Provider 可插拔，策略赛马动态定权 |
| `backtest` | 回测引擎（纯函数，账目可核对） |
| `paper` / `real` | 模拟盘与实盘记录（互相隔离） |
| `risk` | 下单风控（仓位/止损） |
| `screener` / `track` | 选股推荐与信号质量追踪 |
| `web` | HTTP 服务 + React 前端 |

## Roadmap

近期计划：

- [ ] 定时任务：收盘后自动执行信号结算检查与持仓风控检查，无需手动打开页面
- [x] 挂价参考：基于 ATR 波动率给出激进/稳健/保守三档限价建议，展示今日涨跌停并强制裁剪到合法委托范围
- [x] 除权修正：信号追踪用同一信号日的历史收盘价重基准，自动修正分红送转后的在途入场价并保留审计记录
- [ ] 单日亏损熔断：完善单日已实现亏损的统计口径并接入下单拦截

远期想法：

- [ ] ETF 策略参数适配：用低相关 ETF 代表样本验证赛马参数，必要时引入独立参数组
- [ ] 分钟线数据源：支撑 VWAP 基准、日内挂价精算与更细粒度回测
- [ ] 券商 API 自动交易：通过可插拔券商接口接入实盘下单（目前仅调研）
